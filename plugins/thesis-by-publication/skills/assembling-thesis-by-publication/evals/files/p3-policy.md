# What city air quality policy can learn from dense sensor networks

## Abstract
Dense networks of low-cost sensors (LCS) can show pollution differences between streets that a single regulatory monitor misses. Drawing on a field deployment, this paper argues that cities should publish network data alongside official values. We discuss a convolutional neural network (ConvNet) used to fill gaps in the record.

## Argument
Official monitoring in most cities relies on a small number of reference stations. Sensor networks add spatial detail but carry larger errors, so their data should be labeled as indicative. The RMSE of a corrected network is a useful headline number for the public.
